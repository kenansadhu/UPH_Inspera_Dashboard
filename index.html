Metric definitions

Use these definitions when discussing the license

Completed attempt. A monitor row with progress delivered or delivered_blank and a valid candidate start time.

Unique completing candidate. An exact match of the trimmed candidateId text among completed attempts in the calendar year. This may differ from distinct licensed accounts.

Assessment run used. A distinct combination of assessment run title, scheduled start and scheduled end among completed attempts. The export has no explicit run ID.

Year and month. Taken from each candidate's actual startTime, not the assessment's scheduled start.

Minimum-use filter. Retains candidates with at least N completed attempts in that year, then recounts their attempts, runs and monthly activity.

Program attribution. The export has no reliable study-program field. Assessment creator names are staff identifiers, not a verified program mapping.

How to interpret the figures

“Completed attempts” counts delivered candidate exam entries with a start time. “Candidates” counts distinct values in the export's candidateId column after trimming spaces. A person can have more than one account or name variant.

“Assessment runs used” counts distinct title and scheduled-time combinations with completed attempts. The export has no unique run ID or trustworthy study-program field.

The minimum-use rule counts each candidate's completed attempts in the selected calendar year. It removes candidates below that count from all filtered measures. The participation funnel always shows all source entries.

Seat comparisons are scenario checks, not a determination of billable users. Confirm Inspera's licensing definition and the one-program roster before changing the contract.
